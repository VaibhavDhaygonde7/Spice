# Spice

Local music player for linux :)

## Start here

Open a terminal in this folder and run:

```bash
./Spice.sh
```

Or:

```bash
python3 launch.py
```

Organize your collection with one folder per song, then add the parent **Music** folder once:

```text
Music/
  Song A/
    Song A.flac
    lyrics.lrc
  Song B/
    Song B.mp3
```

Basic line-timed LRC:

```text
[00:12.50]A line begins here
[00:17.00]The next line begins here
```
